# 群友评价插件需求

## 目标

群成员可以请求机器人根据本群发言生成一段赞美或友善锐评。插件使用全局 AI 配置，通过 Sender 将结果发回触发指令的群。

## 触发规则

| 指令                     | 评价目标                                                |
| ------------------------ | ------------------------------------------------------- |
| `赞美`、`锐评`           | 发起人，以消息事件中的用户 ID 为准                      |
| `赞美@某人`、`锐评@某人` | 唯一被真实 @ 的群成员，以微信消息元数据中的用户 ID 为准 |

允许指令两端、关键词与 @ 之间，以及提及结束后出现空白。两条关键词均要求整条消息匹配。手打 @、@所有人、真实 @ 多人、提及后包含其他非空白内容时，均忽略该消息。显示名可包含空格，目标身份按成员 ID 匹配。

### 微信 @ 的读取依据

已在「机器人群管-01」中用真实消息 `@张八旦 你好` 验证，消息记录的 `source` XML 内含 `<atuserlist>`，其中记录被提及者的用户 ID。读取器需解析该字段，并将提及列表传给插件。判断目标使用元数据，判断指令是否夹带其他内容使用正文。该验证消息本身不符合评价指令格式。

## 执行流程

1. 解析指令并确定目标用户 ID。
2. 从本地微信数据库读取该用户在当前群截至触发时的最近 N 条发言，排除触发指令本身。按用户 ID 筛选，按时间从早到晚整理为文本。发言不足 N 条时使用已有记录。
3. 将目标显示名和发言文本代入对应提示词，调用全局 AI 模型。目标显示名优先使用群昵称，其次使用微信昵称。
4. 通过 Sender 将生成结果发回原群。没有可用发言时，回复「没有找到该成员可供评价的发言」并结束。模型调用失败时，在任务日志中记录失败原因。

## 配置

| 配置项       | 默认值 | 作用                             |
| ------------ | ------ | -------------------------------- |
| 最近发言条数 | 300    | 每次评价最多读取的目标成员发言数 |
| 回复字数上限 | 300    | 写入模型提示词的目标字数     |

两项均为正整数。插件管理页可设置全局开关、默认开关和默认参数。群配置页可保存本群开关与参数，未配置的群继承默认值。全局关闭时停止所有群的触发。

模型返回的完整正文交给 Sender，由文本协议处理长文本分段。

## 模型提示词

赞美采用五段式，每段以「- 」开头，分别从好奇心、说话方式、思维方式、情感与价值观、整体印象切入。每段参考 50 至 80 字，结合实际发言举例，语气贴近日常群聊。

锐评同样采用五段式，每段以「- 」开头，参考 50 至 80 字。可从表达习惯、思维方式、做事风格、性格反差和整体印象切入，结合实际发言，保持幽默友善。两种模式都会在提示词中加入配置的目标字数。

## 回群格式

```text
@{target} 
{reply}

🕛模型:{model}; 耗时{seconds} 秒
```

## 验收用例

| 场景                                                           | 预期                             |
| -------------------------------------------------------------- | -------------------------------- |
| 成员发送 `赞美` 或 `锐评`                                      | 用发起人在本群的发言生成对应评价 |
| 发送 `赞美 @张八旦`，且元数据中有一个真实 @                    | 按目标成员 ID 读取张八旦的发言   |
| 两个群成员同名                                                 | 按真实 @ 中记录的 ID 选中目标    |
| 手打 `赞美@张八旦`、@ 两人、@所有人，或发送 `赞美@张八旦 你好` | 不触发                           |
| 两个群分别设置不同条数和字数                                   | 各群按本群配置执行               |
| 开启插件后调用模型并生成回复                                   | 原群收到评价正文、模型名和耗时   |
| 全局关闭插件                                                   | 所有群均不触发                   |
