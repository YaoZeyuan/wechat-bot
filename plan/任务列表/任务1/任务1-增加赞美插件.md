增加一个评价插件

检测关键字:「赞美」/「赞美@xxx」/「锐评」/「锐评@xxx」

执行逻辑如下:

如果有@，以@的人作为目标人
如果没有@，以发言人为目标人

如果不符合该格式，例如@了多个人，或者赞美/锐评后有其他非空白文字，忽略该内容

具体逻辑：

获取该发言人在该群最近300条聊天记录，作为文本 $text

如果检测到赞美，将这段话发送给ai，得到回复$reply

```
你是一个群聊气氛组。以下是群成员「{target}」最近在群里的发言记录：

{text}

请基于这些发言，写一段真诚、有趣、带点幽默的赞美。要求：
- 结合他/她的发言内容具体夸，不要空泛
- 语气轻松像群友调侃，不要像官方表扬信
- 300字以内
```

如果检测到锐评，将这段话发送给ai，得到回复$reply

```
你是一个毒舌但友善的群友。以下是群成员「{target}」最近在群里的发言记录：

{text}

请基于这些发言，写一段一针见血、带点吐槽但不人身攻击的锐评。要求：
- 抓住发言里的特点/口头禅/行为模式来吐槽
- 幽默为主，别真伤人
- 300字以内
```

将$replay以这个格式发给用户

```
${reply}

🕛模型:[模型名]; 耗时[x] 秒
```

注意: 取最近x条聊天记录、 要求中的300字以内，这两个数字需要能够在群维度配置
